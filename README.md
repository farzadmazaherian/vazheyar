# واژه‌یار

برنامهٔ شخصی یادگیری واژه‌ها و جمله‌های هلندی و انگلیسی با توضیح فارسی و انگلیسی؛ کاملاً رایگان و بدون سرور.

## راه‌اندازی (یک بار، بدون ترمینال)

1. یک مخزن **Public** در GitHub بسازید و فایل‌های این پوشه را در آن بارگذاری کنید (فقط فایل‌ها، نه پوشه‌های `audio-part`).
   بعد هر پوشهٔ `audio-part-NN` را جداگانه آپلود کنید: واردش شوید و پوشهٔ `audio` داخلش را بکشید. GitHub آپلود خیلی بزرگ را یک‌جا قبول نمی‌کند.
   در به‌روزرسانی‌ها فقط بخش‌هایی که آخر اسمشان شمارهٔ نسخهٔ تازه است دوباره لازم‌اند.
2. در همان مخزن به **Settings ← Pages** بروید.
3. در **Branch** گزینهٔ `main` و پوشهٔ `/ (root)` را انتخاب کنید و **Save** را بزنید.
4. یکی دو دقیقه بعد، نشانی برنامه بالای همان صفحه نمایش داده می‌شود:
   `https://نام‌کاربری.github.io/نام-مخزن/`

راهنمای کامل همگام‌سازی بین لپ‌تاپ و گوشی داخل خود برنامه است: **تنظیمات ← راهنمای گام‌به‌گام راه‌اندازی**.

## فایل‌ها

| فایل | کاربرد |
|---|---|
| `index.html` | خود برنامه |
| `packs.js` | بسته‌های واژه، جمله و مکالمه |
| `asr-worker.js` | تبدیل صدا به متن، داخل مرورگر |
| `audio/` | صدای طبیعی هلندی برای واژه‌ها، جمله‌ها و مکالمه‌ها (ساخته‌شده با صداهای آزاد Piper) |
| `sw.js` | اجرای آفلاین |
| `guide.html` | راهنمای راه‌اندازی همگام‌سازی |
| `manifest.webmanifest` و `icon-*.png` | نصب روی گوشی و لپ‌تاپ |

## امنیت و حریم خصوصی

- هیچ داده‌ای در این مخزن نیست. واژه‌ها، پیشرفت و منابع هر کاربر در مرورگر خودش و، اگر بخواهد، در مخزن **خصوصی** خودش (`vazheyar-data`) ذخیره می‌شود.
- کلید GitHub فقط در مرورگر همان دستگاه می‌ماند و هرگز در فایل‌ها یا پشتیبان نمی‌آید. یک کلید **fine-grained** بسازید که فقط به مخزن داده دسترسی **Contents: Read and write** داشته باشد و تاریخ انقضا داشته باشد.
- «کد اتصال» و کد QR بخش همگام‌سازی کلید شما را دارد؛ فقط برای دستگاه‌های خودتان است.
- PDF، عکس و صدا داخل مرورگر پردازش می‌شوند و به هیچ سروری فرستاده نمی‌شوند. ابزارهای این کار نسخهٔ ثابت دارند و پیش از اجرا با اثر انگشت SHA-384 بررسی می‌شوند.
- فایل‌های خصوصی، مثل درس‌های کتاب درسی، را هرگز در این مخزن عمومی بارگذاری نکنید. بخش **اشتراک‌گذاری ← بررسی امنیت** این را خودکار بررسی می‌کند.
