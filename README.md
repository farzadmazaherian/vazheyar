# واژه‌یار

برنامهٔ شخصی مرور واژه‌ها و جمله‌های هلندی و انگلیسی، کاملاً رایگان و بدون سرور.

## راه‌اندازی (یک بار، بدون ترمینال)

1. در همین مخزن به **Settings ← Pages** بروید.
2. در **Branch** گزینهٔ `main` و پوشهٔ `/ (root)` را انتخاب کنید و **Save** را بزنید.
3. یکی دو دقیقه بعد، نشانی برنامه بالای همان صفحه نمایش داده می‌شود:
   `https://نام‌کاربری.github.io/vazheyar/`

راهنمای کامل همگام‌سازی بین لپ‌تاپ و گوشی داخل خود برنامه است: **تنظیمات ← راهنمای گام‌به‌گام راه‌اندازی**.

## فایل‌ها

| فایل | کاربرد |
|---|---|
| `index.html` | خود برنامه |
| `sw.js` | اجرای آفلاین |
| `manifest.webmanifest` و `icon-*.png` | نصب روی گوشی و لپ‌تاپ |

داده‌های شما در این مخزن نیست؛ در مخزن خصوصی `vazheyar-data` ذخیره می‌شود.
